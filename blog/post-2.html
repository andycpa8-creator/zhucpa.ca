由于低利率变更房屋贷款的银行罚金能不能作为租房费用？

发布于 2020-11-09 · 更新于 2023-03-10 · 552 次阅读 · 分类：税务博客

由于大环境的因素，今年的房屋贷款利率比往年有了很大幅度的降低。有出租房的朋友就会有这个问题：为了更低利率变更房屋贷款，银行收取的罚金能否作为租房费用呢？

Andy Zhu的回答:

房屋贷款罚金属于资本费用（capital expense），是需要根据贷款的期限进行分摊作为租房费用。下面举个例子具体说明：

例子：

小明在2020年为了追求更低的利率，为他的出租房重新签订了为期3年的贷款（贷款期限是2020年6月1日至2023年6月1日）。银行因此收取了$3288的罚金。这个罚金(mortgage penalty) 应该如何申报在税表上？

Andy Zhu的回答:

综上所述，$3288的罚金应该根据贷款期限分摊在2020,2021,2022和2023四年。

2020年6月1日 - 2023年6月1日 总共 1096天。所以罚金(mortgage penalty) 按天算的话是$3/天。

2020年

2020年6月1日 - 2022年12月31日 是 214天。所以在2020年税表上可以申报的罚金(mortgage penalty) 是 $3/天 * 214天 = $642。

2021年

2021年1月1日 - 2011年12月31日 是365天。 所以在2021年税表上可以申报的罚金(mortgage penalty) 是 $3/天 * 365天 = $1095。

2022年

2022年1月1日 - 2012年12月31日 是365天。 所以在2022年税表上可以申报的罚金(mortgage penalty) 是 $3/天 * 365天 = $1095。

2023年

2023年1月1日 - 2023年6月1日 是152 天。所以在2023年税表上可以申报的罚金(mortgage penalty) 是 $3/天 * 152天 = $456。

验证

$642 + $1095 + $1095 +$456 = $3288。
